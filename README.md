# KinderGarden UX Prototype

Кликабельный прототип задания для UX-исследования.

Проект полностью статический: HTML, CSS, JavaScript, изображения и аудио. Серверная часть и база данных не требуются.

## Локальный запуск

Откройте `index.html` через любой локальный статический сервер.

## Деплой

Для публикации укажите корень репозитория как директорию сайта. Команда сборки не требуется, стартовый файл — `index.html`.
